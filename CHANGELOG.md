# Changelog

## v1.2.0

Привет из 2025. Утилита для сверки реестров, которую я писал, пока работал в Яндексе. Тогда она собиралась методом «вставил задачу в GPT-4o, сказал что не работает, повторить». Теперь приведена в порядок.

### Что исправлено
- Суммы, записанные текстом (`1 234,56`, `1,234.56`, `(100,00)`), снова распознаются. В 1.1 они молча превращались в 0.
- Повторяющиеся ID суммируются, а не выкидываются: частичные оплаты больше не теряются. Старое поведение: `duplicate_ids: first` в `config.yaml`.
- `12345`, `12345.0` и ` 12345 ` считаются одним заказом.
- Колонка «Сумма» выбирается раньше «Сумма НДС».
- Прогресс-бар больше не зависает навсегда при неожиданной ошибке.

### Что нового
- Статусы «Нет в акте» / «Нет в реестре» для заказов, которые есть только в одном файле.
- Предупреждение о суммах, которые не удалось распознать.
- Экспорт в `.xlsx`, сортировка таблицы по клику на заголовок.
- `config.yaml` рядом с exe перекрывает встроенный, пересобирать не нужно.

### Файлы
- **Windows:** `Discrepancy_Finder-v1.2.0-windows.exe`
- **macOS (Apple Silicon):** `Discrepancy_Finder-v1.2.0-macos-arm64.zip`. Сборка не подписана: при первом запуске нажми правой кнопкой → «Открыть», либо выполни `xattr -dr com.apple.quarantine "Discrepancy Finder.app"`.
- Рядом с каждым файлом лежит его `.sha256`.
