# Security Notes: Discrepancy Finder

## 📌 Назначение

Программа сравнивает два Excel-файла (реестр и акт) и показывает расхождения. Работает исключительно локально, без доступа к сети.

## 🔒 Работа с персональными данными

- Файлы обрабатываются **только локально**, все расчёты идут в оперативной памяти.
- Данные никуда не передаются, сетевой логики в программе нет.
- Результаты сохраняются на диск **только по запросу пользователя** (`.xlsx` или `.txt`).

## 📝 Логи

- Программа ведёт технический лог в `~/discrepancy_finder.log` (имя задаётся в `config.yaml` → `log_path`).
- В лог пишутся: пути к открытым/сохранённым файлам, названия найденных колонок, количество строк и расхождений, тексты ошибок.
- ID заказов и суммы в лог **не пишутся**.
- Лог можно удалить в любой момент, программа создаст новый.

## 📡 Сетевая активность

- Полностью отсутствует.
- В коде нет обращений к `socket`, `requests`, `urllib`, `http.client` и аналогичным модулям.

## 🧪 Поведение

- Нет `eval`, `exec`, `os.system`, `subprocess`.
- Не внедряет DLL, не обращается к реестру Windows, не прописывается в автозапуск.

## ✅ Проверка

- Исходный код открыт: https://github.com/ilodezis/discrepancy-finder
- Бинарные сборки делаются PyInstaller'ом по `Discrepancy_Finder.spec` (см. `build_instructions.md`).
- Контрольную сумму сборки можно посчитать самостоятельно: `certutil -hashfile Discrepancy_Finder.exe SHA256`.
